name: Story direction
description: User's requested cultural setting, language simplicity, and narration direction for StoryBowl.
---
StoryBowl stories should have an Indian backdrop, using normal language that is easy to understand. Keep English narration unless the user requests another language.

**Why:** The user asked to tune stories for an Indian backdrop and easy language. They found the browser voice too robotic and asked for research into free natural storytelling APIs.

**How to apply:** Preserve this direction when editing story prompts or demo examples. Prefer everyday, varied Indian settings over stereotypes. Do not assume the user approved a specific hosted voice provider merely because they requested research.
