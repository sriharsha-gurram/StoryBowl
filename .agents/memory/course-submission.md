description: The intended use of StoryBowl as a course submission.
---
StoryBowl is intended to be submitted for grading in a course.

**Why:** The owner stated this when asking for an assessment of the app and five high-impact improvements.

**How to apply:** Use this context when discussing improvement priorities and demo readiness. Do not promise a grade or treat an assessment request as permission to implement changes.
